# Prototipo de Figma — Form Recetas

Coloca aquí lo relacionado al prototipo visual que pide el profesor:

- `enlace-figma.txt` → pega el link para compartir de tu archivo de Figma.
- Exporta las pantallas principales como imágenes (`.png` o `.jpg`) y
  agrégalas a esta misma carpeta: login, panel principal, detalle de receta.

Este proyecto de Angular ya sigue la misma paleta de colores y tipografía
definida en `src/styles.css` (Fraunces + Work Sans, tonos calabaza/ciruela),
así que si haces el prototipo en Figma con esos mismos tokens, va a quedar
consistente con la app real.
