02 / Tratamiento

¿Qué información puede utilizar la aplicación?

Los datos dependen de las funciones que uses y de la información que proporciones.

01

Cuenta y acceso

Nombre de usuario, nombre completo, correo electrónico, credencial almacenada como hash, estado de la cuenta y rol asignado.

02

Recetas y comunidad

Recetas que publiques, favoritos, puntuaciones y comentarios vinculados con tu cuenta.

03

Actividad de la tienda

Productos consultados y artículos/cantidades que agregues al carrito para mantener su contenido.

04

Datos técnicos

Información mínima necesaria para mantener la sesión, responder solicitudes y ayudar a proteger la plataforma.

La base de datos contempla tablas para direcciones y métodos de pago; su tratamiento debe describirse con mayor detalle cuando esas funciones se habiliten. La versión actual no ofrece un proceso de pago en línea ni solicita el número completo o el CVV de una tarjeta.

03 / Finalidades

¿Para qué usamos los datos?

✓

Administrar tu cuenta. Identificarte, iniciar sesión, mantener tu sesión y aplicar los permisos de tu rol.

✓

Ofrecer las funciones solicitadas. Mostrar recetas, conservar favoritos, guardar valoraciones y mantener el carrito.

✓

Cuidar la integridad del servicio. Mantener registros necesarios para evitar operaciones no autorizadas y corregir fallos.

✓

Mostrar recetas externas. RecetON consulta la API pública TheMealDB para mostrar contenido de recetas. El proyecto no necesita enviar tus datos de perfil a esa API para realizar una consulta de recetas.

04 / Tus derechos

Conoce tus derechos ARCO

Puedes solicitar el ejercicio de estos derechos respecto de tus datos personales, conforme a la normativa aplicable y a las excepciones legales que correspondan.

A

Acceso

Conocer qué datos personales se tienen sobre ti y obtener información sobre su tratamiento.

R

Rectificación

Solicitar que se corrijan datos inexactos, incompletos o desactualizados.

C

Cancelación

Solicitar la eliminación de datos cuando corresponda. Puede haber supuestos legales que requieran conservarlos o bloquearlos durante cierto periodo.

O

Oposición

Oponerte al tratamiento en los casos previstos por la normativa aplicable, explicando tu situación y los motivos correspondientes.
